# Audit — 2026-09-03 (8th)

Six parallel auditors — new-code correctness (v0.89→v0.92), whole-codebase
security, database/store (+ read-only production queries), documentation
accuracy, test gaps (including fake-vs-real shape comparison), and code
hygiene — every finding verified with file:line evidence before being
reported. Same-day fixes shipped in v0.93.0; the rest is the backlog below.
Prior audits: docs/audit-2026-09-02.md and the memory notes.

## Fixed same-day (v0.93.0)

**Live defects (both would have bitten in production):**
- Heartbeat `llm` label over 64 chars 400'd EVERY beat (profile names are
  unbounded; the failure was a console line) — a healthy bot rendered as
  offline/not-configured forever. Sender now truncates; a drift guard pins
  the 64 on both sides.
- Mgmt `/logs` printed raw JSON: the client never handled the route's actual
  `{ text }` shape and fell through to `JSON.stringify`.

**Security (the audit's one major):**
- Authoring/build confirmation cards clipped the spec to ~14 lines while up
  to 24k chars executed on tap — injected content could ride below the fold.
  The bot now posts the FULL SOUL.md/AGENTS.md/Dockerfile as messages before
  the card, and the card's preview states how many lines it isn't showing.
- `paramValues` (the owner's applied setup answers) leaked to member-role
  viewers and the `?all=1` metadata view via `publicAgent` — now stripped for
  non-owners on both the list and detail routes.

**Correctness:**
- A second allowlisted operator's tap on someone else's authoring card edited
  it to "⏳ Working…" then "Already handled" — destroying the buttons of a
  still-pending proposal. The slow path is now proposer-bound; a stranger's
  tap is a toast ("Not your confirmation") and the card survives.
- Direct SOUL/AGENTS/persona edits now update the template layer
  (`param_files`), so the next "Apply values" renders from the edited content
  instead of silently reverting an approved rewrite to the import-time copy.
- Master-seeding reads moved inside the busy guard (TOCTOU: a concurrent
  save/restore could freeze a torn layer permanently).
- `PUT /params` with an empty body no longer acts as an unannounced reset —
  it 400s asking for `{ values }` or `{ reset: true }`.
- Web setup-values panel now sends `''` for cleared fields — omitting the key
  made the server resurrect the declared default the owner just deleted.
- `update_definition` refuses empty-string soul/agents_md (zero-byte file).
- `TemplateParamSchema` refinements: choice/multichoice must declare options;
  multichoice options may not contain commas (they can never round-trip
  through the comma-joined value).

**Store:**
- `setAIProfileMgmtLlm` is one transaction (a stale/foreign id rolls back
  instead of silently clearing the pick) and a partial UNIQUE index
  (`ai_profiles(owner_id) WHERE mgmt_llm = 1`) enforces single-select in the
  schema.
- `getSnapshot` uses `safeJson` like its sibling (one torn row 500'd restore).

**Hygiene:** sk-ant-oat detection unified case-insensitive across all three
sites; `EDITABLE_FILES` now derives from `CORE_FILES`; stale "no LLM" and
"only place the SDK is touched" headers fixed; mgmt env-var header complete.

**Docs (13 findings, all fixed):** control-interfaces.md no longer claims the
LLM key is required or that SOUL.md is uneditable; slash table matches the
shipped commands; tier table + management-broker.md catalog the six image
tools; pairing regex {4,16}; phantom `list_models` and `list_pending` fan-out
claims removed; §7 policy no longer overstates (no idle auto-disarm; one
global proposal limiter); features.md v0.93 stamp, name-is-the-link, field
types incl. multichoice, Setup values panel; sharing design doc's shipped
type list; ai-profiles.md documents 🛠 Management.

**New drift guards:** SETUP_FIELD ↔ TemplateParamSchema (enums + bounds),
AUTHORING_TOOLS ⊆ manifest + mutate tier, heartbeat 64-char label pair.

## Backlog (as ranked on 2026-09-03; closures annotated 2026-09-04)

> Items 1 (detached confirms, v0.95.0), most of 2 (route tests, v0.94.0 —
> `POST /v1/join` still untested), the cron/snapshot halves of the carried
> item 5, and item 13's env-travel + Phase C are CLOSED. See
> docs/audit-2026-09-04.md for the current picture.

1. **Sequential update processing blocks the mgmt bot** — a confirmed
   `create_agent` awaits the RUNNING poll (≤150s) inside the grammY handler;
   every other message/callback queues behind it. Fix: detached execution
   with a card edit on completion, or @grammyjs/runner.
2. **Zero-HTTP-test routes, by blast radius**: `POST /v1/join`
   (unauthenticated, internet-facing), pairing **approve** (incl. asSelf),
   `send`, snapshot create/restore/delete, `files` GET/PUT, archive/restore,
   member remove, image rebuild/log, peers CRUD, checkpoint, bot-name/sync,
   account routes. Also untested: `completeWithProfile` (both credential
   modes), the 502 proxy mapping, `/v1/mgmt/status` offline derivation,
   broker rate gate, create_agent poll-timeout branch.
3. **`GET/PUT /v1/agents/:id/files` has no size cap** — the snapshot path
   deliberately reads `head -c MAX+1` and refuses oversized files; the file
   routes bypass that guard. Also: the base64-write pattern is re-inlined 3×
   in routes.ts when `writeCoreFile` exists.
4. **Shell-quoting hardening**: `JSON.stringify` as POSIX double-quoting
   leaves `$(…)` live; safe today only because slugs/filenames are validated
   three files away. Move to argv exec or single-quote escaping.
5. **Three diverging .env parsers** (cli.ts, mgmt/index.ts,
   smoke-adopt-full.ts) — extract one.
6. **Undocumented env vars** (10) — above all
   `AGENTCLAW_ALLOW_OWNER_HEADER`, a security-relevant test bypass no
   operator doc mentions.
7. **Tombstone scrub misses `agent_events`** written after delete (prod has
   1: a claim-window timer firing post-delete); `recordEvent` doesn't check
   agent state. `absorbOwnerTelegram` update+delete also wants `transact()`.
8. **`adoptLocalOwnerData` re-key list incomplete** for post-v0.88 tables
   (accounts, group order, mgmt_heartbeat, shares, derived_images,
   telegram_pool.owner_id) — latent, this box is past adoption.
9. **`setShareStatus` has no ownership predicate in SQL** (callers gate).
10. **Dead/duplicated**: `disableOpenclawBot` (dead, logic duplicated inline
    by `quiesceOpenclawBots`), `openclawAgentIdForWorkspace`; `'claude-sonnet-5'`
    mgmt default ×3; `'agentclaw-runtime:latest'` literal ×3; pairing-code
    regex ×5 and placeholder regex ×3 as literals (consistent today, drifted
    before — constants or guards).
11. **`/mode readwrite` is process-global** — one operator arming arms all
    allowlisted operators (single-owner install today; revisit if the
    allowlist grows).
12. Multichoice with legacy option-less declarations: values pass through
    unvalidated (new declarations are now refused; old rows grandfathered).
