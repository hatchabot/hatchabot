# Audit — 2026-09-02 (7th)

Six parallel auditors swept docs accuracy, database structure, hardcoded/drift
constants, dead code, test coverage, and feature gaps — every finding verified
with file:line evidence (and read-only queries against the production DB) before
being reported. This file records what was FIXED same-day and what remains as
backlog. Prior audits: 2026-08-06, 2026-08-25, 2026-08-27 (see the memory notes
and docs/pre-production.md).

## Fixed same-day (deployed and verified live)

**Broken click-paths (the "shipped the button, not the function" class):**
- 📊 Sources button — `openFleetSources` was never defined; implemented.
- ⟳ Sync models button — `syncModels` was never defined (commit 75da04d shipped
  1 line); implemented with the promised add/drop reconcile.
- `scripts/check-web.mjs` now verifies every inline `on*=` handler names a
  defined function — this bug class now fails `npm test` instead of shipping.

**Production data hygiene (verified before/after against the live DB):**
- CLI token with `expires_at NULL` (= eternal, contradicting the bounded-
  lifetime design) — migration backfills NULL to +90 days. The live
  `verification` token now expires 2026-12-01. 1 → 0.
- Orphaned decryptable Telegram bot-token secrets (leaked by best-effort pool
  release on delete) — boot-time sweep deletes unreferenced `telegram/bot/*`
  secrets, logged. 2 → 0.
- Tombstone residue: DELETED agents retained gateway tokens (13), memberships
  with Telegram user IDs (24), invites (7) — one-time migration scrub + the
  delete path now calls `scrubAgentResidue` going forward. All → 0.
- Unguarded `JSON.parse` in row mappers (one torn row would brick every fleet
  endpoint) — `safeJson` with fallbacks.
- Index/collation mismatches — NOCASE indexes for the email/account lookups,
  plus missing `invites.agent_id` and `agents.image` indexes.

**Drift pairs (now enforced by test/driftGuards.test.ts):**
- Web `CLAUDE_MODELS` had resurrected `claude-opus-5` — the model whose absence
  from the claude-cli catalog caused the documented compaction outage; removed
  from web and `scripts/e2e.ts`, and a guard test bans it.
- Embed plugin/model paths (`configWriter` ↔ `Dockerfile.runtime`) — guard test.
- `OPENCLAW_VERSION` default (Dockerfile ARG ↔ build script) — guard test.
- `LLAMA_CPP_PROVIDER_VERSION`: build script now passes it through and warns
  when an OpenClaw bump leaves the plugin pin implicit.
- CLI re-hardcoded the derived-image tag scheme — now imports `deriveTag`.
- Pairing-code regex bounds drifted ({4,12} vs {4,16} across 5 sites) — unified
  at {4,16}; a 13–16 char code was approvable by button but not by the LLM tool.

**Defects and dead code:**
- CLI `--include-memory` missing from `BOOL_FLAGS` — it silently swallowed the
  next argument; fixed, and documented in help (memory is excluded by default).
- Send offered in password mode where shares can never bind (no email) — route
  refuses with a clear message; web hides the button outside identity mode.
- Removed: unused `ollama` dependency, dead `setMembershipDisplayName`, unused
  locals in provision.ts, dead test imports; deduped `OPENCLAW_CONFIG` path
  (3 sites → `openclawConfigPath()`), `SEEDABLE_FILES` → `CORE_FILES`.
- Docs pass: features.md re-stamped and completed (Send/Inbox, checkpoint,
  Sources view, source label), pre-production §9 corrected, design docs marked
  shipped where shipped, stale claims fixed (delete keeps the bot token; adopt
  does carry crons; template memory is opt-in), terminology sweep.

## Backlog (verified open, not fixed today)

Ranked by the auditors' severity; items already tracked in
docs/pre-production.md are not repeated here.

1. **Env vars are not carried by export/migrate/rehost** — transfer.ts exports
   only the bot token; a moved agent silently loses its env secret values (and
   the CLI can't re-add them: env routes are web-only).
2. **Stuck `DELETING` is a trap state** — no reconcile rule, web hides Delete,
   no retry path from any interface.
3. **Missing UNIQUE constraints** — `channels(agent_id)`, `channels(account_id
   NOCASE)` (the one-bot-one-poller invariant is an app-level TOCTOU),
   `data_sources(agent_id, mount_name)`, `hosts` uniqueness. Prod is clean
   today; add as unique indexes when the insert paths are reviewed.
4. **Test gaps** — ~36 routes with zero HTTP tests, including the whole
   share/inbox flow, pairing/approve, and 12 unverified `ownsLocalHost` gates;
   `buildDerivedImage`'s real error paths; CLI mostly untested. (Full ranked
   list in the test-gap auditor's report.)
5. **Interface parity** — CLI lacks: inbox, checkpoint, env vars, move-host,
   pairing deny, crons; web lacks restore-from-file; no interface creates a
   cron; snapshot GET-one/DELETE are dead API surface (snapshots can never be
   pruned).
6. **`GET /v1/accounts` enumerates every account's email to any authenticated
   user** — scope it (recipient picker needs are narrower).
7. **N+1 patterns** in fleet list / pending / usage — harmless at 36 agents,
   fix before 10×.
8. **agent_shares blob retention** — accepted/dismissed rows keep full template
   blobs forever (0 rows today).
9. **Config knobs** — ollama bridge URL (5 hardcodes), `localhost:8080`
   defaults vs PORT, derived-build log dir vs AGENTCLAW_DB, MODEL_PRICES
   duplicated web↔server (serve prices in the usage API).
10. **WORKSPACE_DIR_TEMPLATE bypassed ~15×** — export `workspaceDir(slug)` /
    `OPENCLAW_HOME` helpers and sweep.
11. **Backup nits** — DB copy and volume tarballs not point-in-time consistent;
    non-key `.env` config not captured; runner-host volumes still skipped.
12. **join.html invite warning** gated on `sharedMemory`, which does not govern
    session sharing — a `sharedMemory:false` shared agent invites members with
    no shared-thread warning (pre-production §8).
