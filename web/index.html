👥 Group chats — who it answers in groups, and the BotFather setup
How to enable groups at @BotFather (one-time, per bot)
Two @BotFather settings control this, and neither can be changed by API — message @BotFather in Telegram:
  1. /setjoingroups → pick this bot → Enable (may it be added to groups)
  2. /setprivacy → pick this bot → Disable (may it read all group messages — left on, it only sees /commands and @mentions, which reads as "the bot ignores the group")
Then add the bot to the group like any member. If it was already in the group when you changed privacy, remove and re-add it — Telegram doesn't apply the change retroactively. The agent still answers only admitted members, so pair everyone in the group first. ♻️ Recycled pool bots keep these BotFather settings from their previous life — the check above always shows the live state, so run it rather than assuming defaults.

Runner or cluster?
A runner is another machine under this Hatchabot: same dashboard, same agent list, and Move on an agent's card shifts it between runners. A cluster is a separate Hatchabot server with its own dashboard — Move to another cluster (the card's ⋯ menu) hands an agent over to one, and you manage it there afterwards. What Restore does & where sets live
Restore rolls a single agent's whole volume back to that night (more than a snapshot, which only reverts SOUL/AGENTS/MEMORY) — it overwrites live memory, so the agent is stopped for the swap and restarted after. Each set holds bot tokens and the decryption key in the clear, so it lives in at 0700 and is never downloadable from here.

🧪 Try a newer OpenClaw version, safely — build a candidate, test it on one agent, then promote
  1. Build a candidate. Hatchabot builds a second copy of the runtime with the new OpenClaw version, next to the current one. No agent changes. It takes a few minutes, and the log appears here.
  2. Try it on one agent. The candidate shows up in the list below. Press Try on one agent…, pick a low-stakes agent, and use it for a while. Everything else stays on the current version.
  3. Promote, or back out. Happy? Promote to fleet makes it the default, and each agent moves over on its next rebuild. Not happy? The ✕ by the agent's name puts it back, and you can delete the candidate.

Good to know

  
A few concepts that aren't obvious at first.


  

    

      Changing an agent
      
    
        
  • Model changes are instant — pick a model and it takes effect on the next message. No rebuild.
    • 
        
  • Most other changes apply on the next Rebuild — AI source, data, environment, rich messages, peers. The agent's card says so.
    • 
        
  • A plain Rebuild keeps your conversation (it resumes). Only switching the AI source starts a fresh thread — and that offers "Save conversation to memory first."
    • 
      

    


    

      Memory & the model command
      
    
        
  • Agents write durable facts to memory as they go. Chat → Memory saves the current conversation on demand — handy before a source switch or a long archive.
    • 
        
  • Typing /model to the bot in Telegram is a temporary this-conversation switch — it reverts. Change models in the app to make it stick.
    • 
      

    


    

      Archive & limits
      
    
        
  • Archive keeps everything the agent learned and hands its bot back to the pool. Restoring gives it a new bot & link to reshare. Save to memory first before a long archive.
    • 
        
  • Archived agents don't count toward your agent limit, and settings changes reach them when you restore.
    • 
      

    


    

      Google connections
      
    
        
  • Reconnecting an account detaches its agents — always reconnect, then re-attach it.
    • 
        
  • Each Google service (Sheets, Docs, Contacts…) must be enabled once in your Cloud project — separate from approving the scope.
    • 
      

    


    

      Talking & safety
      
    
        
  • Agents can consult each other — ⚙ → 🔗 Peers (same-owner only; needs a rebuild, since it installs a tool).
    • 
        
  • Telegram is the open door: anyone you admit to an agent can direct it. Be mindful of powerful agents (that send email or write files) with a wide audience — ⚙ → 🛡 Security shows each agent's exposure.
    •
