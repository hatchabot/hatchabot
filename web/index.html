On — MEMORY.md is a common log for every member: entries are tagged with who said them, and anything written may surface to other members. Changing AI source restarts the agent on a different engine, which ends the current Telegram conversation. 👥 Group chats — who it answers in groups, and the BotFather setup
How to enable groups at @BotFather (one-time, per bot)
Two @BotFather settings control this, and neither can be changed by API — message @BotFather in Telegram:
  1. /setjoingroups → pick this bot → Enable (may it be added to groups)
  2. /setprivacy → pick this bot → Disable (may it read all group messages — left on, it only sees /commands and @mentions, which reads as "the bot ignores the group")
Then add the bot to the group like any member. If it was already in the group when you changed privacy, remove and re-add it — Telegram doesn't apply the change retroactively. The agent still answers only admitted members, so pair everyone in the group first. ♻️ Recycled pool bots keep these BotFather settings from their previous life — the check above always shows the live state, so run it rather than assuming defaults.

🎙 Voice & media — a Gemini key lets every agent transcribe voice notes
With a Gemini API key (free tier at aistudio.google.com), every agent can transcribe Telegram voice notes — audio is sent to Gemini for transcription, then answered by the agent's own AI as usual. 🔎 Fleet search key — a Brave key upgrades every agent from DuckDuckGo
Every agent has web search built in (keyless DuckDuckGo). Paste one Brave Search API key here and the whole fleet upgrades to Brave on each agent's next Rebuild — better results, proper rate limits. A per-agent BRAVE_API_KEY env var overrides it (its own quota). Shared credential — same caveats as the media key.
The machines this cluster runs agents on. This machine is the built-in runner; add a runner to run agents on other machines under this dashboard.
How runners & moves work
A runner is a remote Docker endpoint — one AgentClaw, many machines. Agents here can use your Claude Max login; a runner agent uses an API-key source or a Claude Max setup-token (claude setup-token) — the machine-login Max source is desktop-only. Move an agent between runners with Move on its card; Move to another cluster (in the card's ⋯ menu) sends it to a different AgentClaw server entirely.

A nightly job saves each agent's entire memory plus the control-plane registry — one dated set per run, kept 14 days.
What Restore does & where sets live
Restore rolls a single agent's whole volume back to that night (more than a snapshot, which only reverts SOUL/AGENTS/MEMORY) — it overwrites live memory, so the agent is stopped for the swap and restarted after. Each set holds bot tokens and the decryption key in the clear, so it lives in at 0700 and is never downloadable from here.

What's baked in, and the upgrade rule
The image bakes in the OpenClaw version, the Claude CLI, the gog Google Workspace CLI, the local embedding model (semantic memory search), the PDF/OCR stack (tesseract, ocrmypdf, poppler, qpdf — so scanned pages are read, never silently skipped), and PDF creation (pandoc + weasyprint — markdown/HTML into real PDFs). Upgrading the OpenClaw version is a deliberate, separate command-line step — image packages can be rebuilt without touching it. Web search is always on (keyless DuckDuckGo); one Fleet search key in AI sources upgrades everyone to Brave.
