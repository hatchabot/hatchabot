The agent sees these at /data/<folder>. Anyone who can message it can ask about their contents — and for writable folders, change or delete them, so grant that sparingly. Applies on the next Rebuild.
A git repo, cloned into the agent's own space (not your disk). AgentClaw generates a deploy key — you don't paste your own. After adding, copy that key into the repo (its 🔑 Deploy key button below), add it on GitHub, then Rebuild. Read-only, or read-write so it can commit & push.
Injected into the agent as environment variables (e.g. an API key a script needs). Values are write-only — stored encrypted, never shown again; you can only replace or remove them. Applies on the next Rebuild. Names AgentClaw manages (ANTHROPIC_API_KEY, PATH, …) are reserved.
