Management bot — checking…
Optionally control your fleet from Telegram: list, start/stop and rebuild agents, and approve join requests — every change confirmed with a tap. It runs as its own process, so set it up from a terminal on the server:
agentclaw mgmt-bot setup
A nightly job saves each agent's entire memory, the control-plane registry, and the key to decrypt it — one dated set per run, kept 14 days. Restore rolls a single agent's whole volume back to that night (more than a snapshot, which only reverts SOUL/AGENTS/MEMORY) — it overwrites live memory, so the agent is stopped for the swap and restarted after. Each set holds bot tokens and the decryption key in the clear, so it lives in at 0700 and is never downloadable from here.
